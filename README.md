# VOLT RUSH — неоновый 3D endless runner

Оригинальная браузерная 3D-игра в духе классических раннеров с рельсов: три полосы,
бесконечно генерируемый город, поезда, монеты, павер-апы, персонажи, магазин,
миссии и локальный лидерборд.

**Стек:** HTML5 + CSS3 + JavaScript (ES modules) + Three.js (подключается через
`importmap` с CDN `cdn.jsdelivr.net`). Внешних ассетов нет: вся графика —
процедурная (примитивы Three.js), весь звук — синтезируется Web Audio API.

## Как запустить локально

Игра использует ES-модули, поэтому нужен любой статический HTTP-сервер
(открывать `index.html` напрямую через `file://` браузер не разрешит).

```bash
cd runner
python -m http.server 8000
```

Затем откройте <http://localhost:8000/>.

Альтернативы:

```bash
npx serve .        # Node.js
```

## Как выложить на GitHub Pages

1. Создайте репозиторий и положите файлы так, чтобы `index.html` лежал
   **в корне репозитория** (структура: `index.html`, `css/`, `js/`, `README.md`).
   Если репозиторий уже содержит сайт — кладите содержимое этой папки
   в корень (или в любую подпапку: все пути в проекте **относительные**,
   поэтому игра работает и из подпапки вида `https://user.github.io/repo/runner/`).
2. Закоммитьте и запушьте:

   ```bash
   git init
   git add .
   git commit -m "VOLT RUSH"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
4. Через минуту игра будет доступна по адресу
   `https://<user>.github.io/<repo>/` — и сразу запускается (экран меню с PLAY).

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Смена полосы | `←` / `→` (или `A` / `D`) | свайп влево/вправо, кнопки ◀ ▶ |
| Прыжок | `↑`, `W`, `Пробел` | свайп вверх, тап, кнопка ▲ |
| Скольжение | `↓`, `S` | свайп вниз, кнопка ▼ |
| Пауза | `Esc` / `P` | кнопка `II` |

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | разметка, `importmap` для Three.js, все экраны |
| `css/style.css` | неоновый интерфейс, HUD, адаптивность |
| `js/main.js` | bootstrap: рендерер, свет, ввод, игровой цикл |
| `js/settings.js` | localStorage-состояние, i18n (RU/EN), миссии, качество |
| `js/game.js` | игровой цикл: скорость, спавн, коллизии, очки, камера, частицы |
| `js/world.js` | бесконечный город: рельсы, платформы, тоннели, здания, пул сегментов |
| `js/obstacles.js` | барьеры, ящики, ворота, стены, движущиеся блоки, поезда |
| `js/coins.js` | линии/дуги/цепочки монет, магнит |
| `js/powerups.js` | MAGNET, JETPACK, SHIELD, SUPER JUMP, SCORE BOOST |
| `js/player.js` | физика бегуна, прыжок, скольжение, визуал павер-апов |
| `js/characters.js` | 8 персонажей из примитивов + анимация бега |
| `js/menu.js` | меню, выбор персонажей (3D-превью), магазин, миссии, рекорды |
| `js/ui.js` | HUD, таймеры павер-апов, всплывающие сообщения |
| `js/audio.js` | синтез звуков и процедурный эмбиент-луп (Web Audio API) |

Сохранения (рекорды, монеты, персонажи, миссии, настройки) хранятся в
`localStorage` браузера.
